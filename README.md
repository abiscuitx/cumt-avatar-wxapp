## 项目简介

该小程序用于生成和分享矿大头像戳素材，包含若干页面（首页、导航、分享等）和资源。适合作为校园活动、纪念日素材生成工具。

项目特性：
- 轻量级微信小程序实现，易于本地预览与打包。
- 内置图片资源与模板，支持分享到社交平台。

## 快速开始

1. 安装并打开微信开发者工具。
2. 将本目录作为小程序项目目录打开（或使用 `miniprogram` 编译工具）。
3. 在工具中预览并进行本地调试。

## 项目架构

```
cumt-avatar-wxapp-122th/
├── app.js
├── app.json
├── app.wxss
├── pages/             # 小程序页面
│   ├── index/         # 首页
│   ├── nav/           # 导航页面
│   └── share/         # 分享页面
├── resource/          # 图片等静态资源
├── project.config.json
├── sitemap.json
└── README.md
```

### 核心功能/目录

#### 首页（pages/index）
负责入口展示、素材选择与生成入口逻辑。

#### 导航（pages/nav）
提供功能跳转与说明信息。

#### 分享（pages/share）
实现生成结果的分享预览与保存。

### 工程化配置

项目使用标准微信小程序配置文件：`app.json`、`project.config.json`，可以在微信开发者工具中直接导入并运行。

## 开发说明

本项目为前端微信小程序工程，主要通过小程序自带的生命周期与页面通信实现功能。组件位于 `components/`（如存在）中。

### 技术栈

- 微信小程序原生（WXML/JS/WXSS）
- 少量前端工具链用于打包与资源管理（如需）

### 其他开发说明

- 请确保在本地使用微信开发者工具进行测试。
- 任何敏感密钥或环境变量请放入 `.env` 并加入 `.gitignore`（仓库已包含忽略规则）。
